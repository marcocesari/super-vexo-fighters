# super-vexo-fighters
Super Vexo Fighters: a Super Smash Bros. Ultimate-inspired fighting game set in the Super Vexo universe, made with p5.js. 11 fighters built from 3D shapes battle on 3 stages with Smash rules: damage %, knockback, double jumps, shields, dodges, ledge grabs. Stock or Stamina mode, 2 players (keyboard/gamepad) or vs CPU. Made by Marco.
